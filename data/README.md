# data/

Download the videos (link: main README §3) and extract them here:

```
data/<video_id>/frames/000000.jpg, 000001.jpg, …   # file number = frame index t
```

Video ids: `easy_01`, `easy_02`, `normal_01`, `normal_02`, `hard_01`, `hard_02`. The contents of
`data/` are not committed; do not redistribute the clips outside this course.
